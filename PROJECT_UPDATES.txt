write it here in the same session.


HOW TO READ THE FRONTEND (src/)
-------------------------------
Open the folder that matches the screen you are working on.

  app/          App start only: providers + router.
  views/        Screens, split by who sees them.
    public/     Website: home, templates, pricing, support.
    auth/       Sign in / register (customer + admin login).
    customer/   Logged-in customer dashboard and profile.
    admin/      Admin studio: users, accounts, coupons, bills, plans, templates.
    wish/       Recipient share page (/w/:token). Full-screen experience.
  services/     All data access. Views and hooks call services, not raw API.
    http.ts             fetch wrapper
    auth.service.ts     login, register, logout, profile
    catalog.service.ts  occasions, templates, pricing
    coupons.service.ts  public coupon validate / quote
    projects.service.ts customer projects
    uploads.service.ts template + project media files
    admin.service.ts    live users + remaining admin demo lists
  shared/       Reuse only (used by more than one view).
    components/ui       Button, Input, Card, Modal
    components/common   Logo, cards, empty/loading states
    components/layout   PageContainer, MobileTabBar, AppTopBar
    hooks               useAuth, useProjects, useTemplates, ...
    store               auth + UI state
    data                demo / static data until the API is live
    constants, types, lib
  assets/       Images
  styles/       Global CSS

Reuse shortcuts (index files):
  import { Button, Input, Card } from '@/shared/components/ui'
  import { useAuth, useProjects } from '@/shared/hooks'
  import { login, getProjects } from '@/services'
